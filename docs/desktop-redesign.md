# Desktop redesign review — 0.2.0

Repository review: existing React 19/TypeScript/Vite renderer, Tauri 2/Rust native boundary, TanStack Query server state, Zustand selected-profile persistence, Motion transitions, Lucide icons, plain CSS plus Tailwind import. All eight pages and their shared modal/toggle/empty states were inspected. Native SQLite, OS credential storage, Microsoft PKCE, verified game/loader downloads, updater and profile UUID isolation remain the underlying mechanisms. No backend rewrite or framework migration.

Observed problems: large rounded Nunito type and oversized headings; repeat account/profile/launch information in header, sidebar and greeting; marketing banner and three-step strip displace Play; profile menus have no removal confirmation; profile grids waste desktop space; download counters look like aggregate progress although they are stage-local; discovery and installed mods are interleaved; controls use inconsistent density. Existing limitations: no managed-mod uninstall/enable/update API, no native installed-version inventory or measured transfer bytes/s, no shared cape service/collection, no account skin image endpoint. Do not invent those states or controls.

Direction: graphite workspace, subtle separators, 4/8px spacing, 6/8/12px radii, Windows-native Segoe UI Variable / Segoe UI typography, precise orange primary action, compact collapsible sidebar, one account area, profile library rows and a central launch workspace. Existing owner pumpkin and original generated landscape are reused; no competitor code, layout or assets copied. Native Windows decorations remain enabled for real window controls and DPI handling. Marketing copy is removed from normal flows.

References reviewed for product quality only: https://norisk.gg/ , https://dawn.gg/ , https://linear.app/ . No social counts, catalog cosmetics or unsupported features are imported.


Verification: all eight pages inspected at 1280×720, 1366×768, 1600×900 and 1920×1080; no horizontal overflow in the 32 combinations. Additional 1024×576 and 853×480 logical viewport checks cover constrained layouts, not actual Windows OS DPI acceptance. Profile creation with Fabric/Forge catalog lookup, dialog outside-click retention, selected-profile persistence, compact sidebar, appearance persistence/reset, profile export, removal cancellation/confirmation and Modrinth Sodium discovery exercised. Only the temporary test profile was removed; original browser profiles and selection restored. Screenshots retained under ignored .local/ui-redesign. No new authenticated gameplay, real Windows DPI or clean-machine upgrade acceptance is claimed.

Implemented: shared compact profile rows, keyboard-accessible tabs, focus-managed dialogs, removal confirmation, reduced-motion preference, accurate launch/process states and throttled progress rendering. Dev preview loader metadata now uses a bounded server-side official-catalog proxy; native installation remains behind typed Rust commands. Missing mod-management and shared-cape APIs are not represented as working controls.
