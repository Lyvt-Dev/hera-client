# Hera Companion — model update (mod 0.14.0)

Right Shift → Hera Companion. Module and voice stay opt-in. Uses the owner's supplied hera.bbmodel instead of the earlier generated billboard images. Runtime geometry: 74 textured cubes, original bone hierarchy, cube pivots/rotations, per-face UVs, main texture and emissive glowmask. No new rendering-library dependency or copied reference implementation.

All eight supplied animation clips are mapped: idle while standing, walk when moving, run when sprinting, swim in water, fly_hover when airborne or on the shoulder, fly when moving in creative flight, fly_glide while gliding, hurt after receiving damage. Settings can select any clip explicitly for testing. The asset contains no seated animation; shoulder mode uses hover rather than claiming a supplied sit clip. Automatic mode changes to the right shoulder after five idle seconds; pinned following and shoulder modes remain available. No server entity, packets or visibility to other players.

The original curves and limited Molang expressions are baked at 60 samples/second by scripts/import_hera_model.py. The importer allows explicit arithmetic, degree-based sin/cos, min/max/clamp and query.anim_time; it does not execute arbitrary source code. Bézier time/value handles are sampled during import. Runtime interpolates adjacent samples; it does not evaluate expressions. This sampling approximates continuous curves to 1/60-second intervals. Native world vertex consumers supply depth testing and world lighting. Geometry is cached; two passes provide base texture and glow. No FPS claim without measurement.

Following is a local floating companion with a bounded catch-up teleport when far away, not ground navigation or a colliding server mob. Shoulder representation is hidden in first person. Caption projection is used only while a caption is visible. The old generated 2D sprite files have been removed.

Three opt-in synthesized English voice clips and German captions remain from 0.13.1. Audio is local Java Sound with master-volume scaling and a cooldown. No microphone or online speech service. The model and its embedded textures were supplied by the owner for this integration; no additional third-party character pack or code was fetched. No separate third-party asset license was included in the supplied file. Original creator attribution/public distribution rights have not been independently established; owner provenance should be retained before redistribution beyond the requested project.

Implemented and automated-test evidence is recorded in status.md. Actual model appearance, UV orientation, animation poses, glow blending, shoulder placement and sound playback still require the owner's in-game test; a successful build does not prove those visual results.
